	      <span class="fancy-text">Infinite Jest</span> is a <em>The Sims</em> machinima series based on David Foster Wallace’s novel.
	      The book’s structure—resembling a Sierpiński triangle and a game of professional tennis—is translated into fragmented videos designed for nonlinear viewing.
	      Any clip can be a starting point; the beginning contains the end, the end folds into the beginning, but they don’t necessarily belong to the same story.
	      <br><br>
	      While <em>Infinite Jest</em> has a narrative, it emerges from overlapping storylines. Machinima, as a medium, always engages with the internal structures of the game it’s created in.
	      In this case, <em>The Sims</em> offers a more fitting way to reimagine the novel’s themes than a conventional adaptation.
	      <br><br>
	      The 25-year history of <em>The Sims</em>—its lore, mechanics, and linguistic and behavioral clichés—unexpectedly aligns with Wallace’s use of repetition and nonverbal functions of clichés.
	      Most of the machinima is filmed in <em>The Sims 4</em>, a game often criticized by its community, which I associate with the novel’s Subsidized Time era.
	      Events set before Subsidized Time are recreated in earlier <em>The Sims</em> installments.
	      <br><br>
	      The series employs different filming techniques and approaches to character interactions, from recreating game conditions described in the novel to observing unscripted interactions between a character and players in <em>The Sims Online</em> (FreeSO).

	  <script>
	    const container = document.getElementById('text-container');
	    const baseText = document.getElementById('base-text').innerHTML;
	
	    // Fractal clone on click
	    container.addEventListener('click', (e) => {
	      for (let i = 0; i < 5; i++) {
	        const clone = document.createElement('div');
	        clone.className = 'fractal-text';
	        clone.innerHTML = baseText;
	
	        const rect = container.getBoundingClientRect();
	        const x = e.clientX - rect.left;
	        const y = e.clientY - rect.top;
	
	        clone.style.left = `${x}px`;
	        clone.style.top = `${y}px`;
	
	        const scale = 0.5 + Math.random() * 0.5;
	        const angle = Math.random() * 360;
	        const dx = (Math.random() - 0.5) * 500;
	        const dy = (Math.random() - 0.5) * 400;
	
	        clone.style.transform = `translate(${dx}px, ${dy}px) scale(${scale}) rotate(${angle}deg)`;
	        container.appendChild(clone);
	
	        // Fade effect and removal after transition
	        setTimeout(() => {
	          clone.style.opacity = 0;
	          setTimeout(() => clone.remove(), 1400); // Removes clone after opacity transition
	        }, 100);
	      }
	    });
	
	    // Make the text-container draggable
	    let isDragging = false;
	    let offsetX, offsetY;
	
	    container.addEventListener('mousedown', (e) => {
	      isDragging = true;
	      offsetX = e.clientX - container.offsetLeft;
	      offsetY = e.clientY - container.offsetTop;
	    });
	
	    document.addEventListener('mouseup', () => {
	      isDragging = false;
	    });
	
	    document.addEventListener('mousemove', (e) => {
	      if (isDragging) {
	        container.style.left = `${e.clientX - offsetX}px`;
	        container.style.top = `${e.clientY - offsetY}px`;
	      }
	    });
	  </script>
